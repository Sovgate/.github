# Sovgate

Sovgate helps businesses get paid online and in person: checkout, payment links, invoices, subscriptions and card readers, all in one account.

This organization holds our official libraries and the specification of the Sovgate API.

## Libraries

All our libraries are in development and not yet released. When one is, its repository will explain how to install and use it.
